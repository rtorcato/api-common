# @rtorcato/api-common

Framework-agnostic building blocks for Node.js APIs: HTTP errors, auth, config, logging, validation, rate limiting, timeouts, health checks, webhooks, uploads and OpenAPI, with Express and Hono adapters.

Each feature is a subpath export. There is no root export, so you load only what you import.

```bash
npm install @rtorcato/api-common
```

```ts
import { NotFoundError } from '@rtorcato/api-common/errors'
import { errorHandler } from '@rtorcato/api-common/errors/express'
```

Third-party libraries such as `express`, `hono`, `zod` and `jsonwebtoken` are optional peer dependencies. Install the ones the subpaths you use need. `@rtorcato/js-common` is the only dependency installed for you. Requires Node.js 24 or newer.
